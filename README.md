# bsynth

**bsynth** is a web-based synthesizer based on [adsr](https://github.com/satelllte/adsr), the open source synth built with the [Elementary Audio](https://www.elementary.audio/) framework.

<img src="./public/og-image.png">

Additional features such as musical typing, drum programming, and recording features have been added.
